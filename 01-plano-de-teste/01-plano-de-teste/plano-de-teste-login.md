## Plano de Teste — Login

## 1. Informações do projeto

Projeto: Testes da funcionalidade de Login
Sistema: QAZANDO Shop E-Commerce
URL: https://www.automationpratice.com.br/
Funcionalidade: Login
Tipo de projeto: Teste funcional
Responsável: Lucille Lima


## 2. Objetivo

Validar a funcionalidade de autenticação da aplicação, verificando se o sistema apresenta comportamento esperado diante de diferentes combinações de dados de entrada.


## 3. Escopo

## 3.1 Dentro do escopo

Serão testados:
● Tela de Login;
● Campo de e-mail;
● Campo de senha;
● Botão "Entrar";
● Login com credenciais válidas;
● Login com senha inválida;
● Login com e-mail inválido;
● Login com usuário não cadastrado;
● Campos vazios;
● Mensagens de validação;
● Redirecionamento após Login.

## 3.2 Fora do escopo

Não fazem parte deste projeto:
● Cadastro de usuários;
● Alteração de dados do usuário;
● Processo completo de recuperação de senha;
● Checkout;
● Pagamento;
● Área administrativa;
● Testes de performance;
● Testes de segurança avançados;
● Testes de carga.


## 4. Estratégia de testes

Serão realizados testes:

Funcionais
Positivos
Negativos
De validação
De interface
De campos obrigatórios

Também serão utilizadas técnicas como:

Particionamento de equivalência
Análise de valores-limite
Testes baseados em cenários
